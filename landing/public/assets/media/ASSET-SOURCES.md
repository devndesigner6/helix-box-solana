# Landing visual sources

Reference: https://lunel.dev/ (downloaded October 3, 2026).

- gradient.webp: /img/hero/bg.webp
- agents.png: /img/feature/ai.png (shared coding-agent interface).
- editor.png: /img/feature/editor.png (shared editor interface).
- git.png: /img/feature/git.png (reference only; not used in the public page because it contains Lunel project names).
- android.svg: /svg/android.svg.
- github.svg and chevron.svg: inline icons exported from the reference page.

The complete reference stylesheet, images, icons, and videos were downloaded into a temporary browser asset bundle for inspection. Original branded marketing videos and contributor avatars are not published as HelixBox content. The existing repository's upstream MIT license and copyright notice remain intact; this source list records provenance rather than assigning a license to the separately hosted website media.

The active demo is Hemanth's Solana walkthrough at https://youtu.be/KXF1TQKWFDM. Its real YouTube thumbnail is displayed first; the privacy-enhanced YouTube player loads after a visitor activates it. The older local `helixbox-preview.mp4` and demo stills are retained project assets from Hemanth's earlier `Helixbox demo.mp4` recording, not the active hero video. HelixBox and agent logos are existing project assets. Font files are the existing VT323, Source Serif 4, and JetBrains Mono files; no reference font is substituted.

Animated utility panels and connection illustrations are HTML/CSS previews, not live telemetry or measured benchmarks. Motion is disabled for visitors who request reduced motion.
